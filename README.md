# QuickDev — Free Online Developer Tools

**18 free tools that run 100% in your browser. No signup. No tracking. No ads (for now).**

Your data never leaves your device. All processing happens client-side.

## Tools

| Category | Tools |
|----------|-------|
| **Data** | JSON Formatter, CSV ↔ JSON Converter, JWT Decoder |
| **Encoding** | Base64 Encoder, URL Encoder, HTML Entity Encoder |
| **Code** | Regex Tester, SQL Formatter, CSS/JS/HTML Minifier, Diff Checker |
| **Generation** | UUID Generator, Password Generator, QR Code Generator, Cron Parser |
| **Converters** | Timestamp Converter, Color Converter, Markdown Preview |
| **Reference** | HTTP Status Codes |

## Why QuickDev?

- 🔒 **Private** — everything runs locally, your data stays on your device
- ⚡ **Fast** — zero server round-trips, instant results
- 🎨 **Clean** — dark theme, no distractions
- 📱 **Responsive** — works on desktop and mobile
- 🆓 **Free** — no paywalls, no registration

## Tech Stack

Pure HTML, CSS, and JavaScript. Zero build steps. Zero frameworks. Hosted on GitHub Pages.
